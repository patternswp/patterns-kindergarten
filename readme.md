# Patterns Kindergarten

> **Patterns Kindergarten** is a colorful and engaging block-based WordPress theme designed for kindergartens, preschools, daycare centers, and child-focused organizations.

## Description

Patterns Kindergarten is a vibrant and playful Full Site Editing (FSE) WordPress theme crafted for kindergartens, preschools, daycare centres, and other child-focused organizations. It provides all the tools you need to create a fun and welcoming online presence. Use this block-based theme to highlight your educational programs, staff, and activities. With its FSE capabilities, Patterns Kindergarten empowers you to customize headers, footers, layouts, and global styles directly within the WordPress Site Editor.

## Features

- **Full Site Editing (FSE):** Customize every aspect of your website using the WordPress block editor.
- **Playful Design:** Perfect for kindergartens, preschools, and other child-focused organizations.
- **Responsive Layouts:** Designed to look great on all devices.
- **Pre-designed Templates:** Includes layouts for showcasing educational programs, services, testimonials, faq, facilities, contact, about page, staff, and activities.
- **Custom Block Patterns:** Simplify website creation with ready-to-use patterns.
- **SEO Optimized:** Built with best practices for improved search engine rankings.
- **High Performance:** Lightweight and optimized for fast loading.

## Getting Started

### Installation

- Clone the repository to your `/wp-content/themes/` directory:

  ```bash
  git clone https://github.com/patternswp/patterns-kindergarten.git
  ```

- Or download and upload the theme files to `/wp-content/themes/patterns-kindergarten`.

### Activate the Theme

Activate the theme via the WordPress admin dashboard under **Appearance > Themes**.

### Start Customization

With Full Site Editing support, you can customize the theme through the WordPress Site Editor by navigating to **Appearance > Editor**. Modify headers, footers, layouts, and global styles to suit your kindergarten needs.
